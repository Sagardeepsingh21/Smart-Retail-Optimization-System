# Retail-Pulse – Smart Retail Management System

Retail-Pulse is a smart retail management system designed to help retailers monitor sales, manage inventory, analyze customer buying patterns, and support better business decisions using data analytics.

### Features
- Sales and inventory monitoring
- Inventory forecasting and low-stock alerts
- Customer buying pattern analysis
- Pricing optimization and data-driven insights
- Dashboard for retail performance monitoring

### Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MongoDB

### Research Publication
Research paper: [An Integrated Decision Support System for Smart Retail Management Using Data Analytics](https://ieeexplore.ieee.org/document/11726947)
